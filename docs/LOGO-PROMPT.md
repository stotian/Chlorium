# Chlorium logo

Original image: `logo.png`. Created with OpenAI image generation, transparent
background, using the Bismuth and official Sodium icons as visual references.

Prompt direction: original rounded dark-green Geode-style mod badge; luminous
lime, emerald and turquoise rim; bold beveled C made from crystalline paths;
white/mint flame or droplet in the centre; legible at small sizes; no words,
no exact copy of either reference. A smooth, compact silhouette with a
transparent exterior.

References: IliasHDZ/Bismuth `logo.png` and CaffeineMC/sodium
`common/src/main/resources/sodium-icon.png`. References are kept separately in
`references/` and are not shipped as Chlorium branding.
