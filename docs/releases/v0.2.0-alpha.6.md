# Chlorium v0.2.0-alpha.6 — candidate compilee, verification en jeu suspendue

Le paquet normal retire le cache de transferts d'atlas et ses hooks. GD reprend
integralement ses transferts GPU et son marqueur dirty. Les calculs
mathematiques natifs repetes peuvent toujours etre reutilises.

Ce changement elimine le chemin de Chlorium susceptible de supprimer un envoi
sur la base d'anciennes donnees de geometrie. Il s'agit d'une mitigation
conservative des ecrans noirs, sans attribution demontree de tous les episodes
rapportes a ce cache.

Compilation effectuee pour GD 2.2081 / Geode 5.11.2, Windows x64. Verification
statique des identites du paquet : chemin GPU natif present, implementation
de l'ancien cache absente. **Aucun nouveau niveau ni test de regression lance
apres la consigne d'arret.** Le changement n'est pas valide en jeu et ne prouve
pas 60 FPS stables. L'installation principale reste sur sa version precedente.

Les sources du cache retire sont conservees pour investigation, avec une
option reservee aux audits. Elles ne peuvent plus etre packagees comme une
version normale. L'alpha.5 mesuree et ses notes restent conservees separement.

Voir `docs/BLACKSCREENS-ALPHA6.md` pour la modification et les limites des
observations avec les mods personnels avant l'arret des essais.
