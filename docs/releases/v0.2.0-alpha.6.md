# Chlorium v0.2.0-alpha.6 — transferts GPU natifs

Le paquet normal retire le cache de transferts d'atlas et ses hooks. GD reprend
integralement ses transferts GPU et son marqueur dirty. Les calculs
mathematiques natifs repetes peuvent toujours etre reutilises.

Ce changement elimine le chemin de Chlorium susceptible de supprimer un envoi
sur la base d'anciennes donnees de geometrie. Il s'agit d'une mitigation
conservative des ecrans noirs, sans attribution demontree de tous les episodes
rapportes a ce cache.

Compilation effectuee pour GD 2.2081 / Geode 5.11.2, Windows x64. Verification
statique des identites du paquet : chemin GPU natif present, implementation
de l'ancien cache absente.

Apres reprise autorisee, quatre parcours avec les mods personnels et reglages
verifies, LDM OFF, SHAKE OFF, compteur FPS, libelles AVEC/SANS, collisions natives :

- Grief auto 88952972 : 0-40 % dans les deux modes, 15 episodes sombres chacun.
- Heliopolis auto 129598490 : fin atteinte dans les deux modes, un episode
  sombre chacun vers 99.075 %.
- Aucune mort ni crash. Aucun episode quasi noir supplementaire detecte avec
  alpha.6 dans ces deux comparaisons.

Une paire par niveau, sans verification de chaque pixel ou texture. Les FPS
du diagnostic comprennent son cout ; **60 FPS stables non atteints**. Le cache
mathematique n'a aucun appel cible dans ces parcours, donc aucun gain ne peut
y etre attribue a cette optimisation. L'alpha.6 est installee localement ;
le paquet alpha.5 precedent est sauvegarde.

Les sources du cache retire sont conservees pour investigation, avec une
option reservee aux audits. Elles ne peuvent plus etre packagees comme une
version normale. L'alpha.5 mesuree et ses notes restent conservees separement.

Voir `docs/BLACKSCREENS-ALPHA6.md` pour la modification et
`docs/VALIDATION-ALPHA6-20261023.md` pour les chiffres et limites des essais.
