## Chlorium

Mainteneur de ce depot : **stotian**. Adaptation independante pour GD 2.2081
et Geode 5.11.2, corrections de compatibilite, optimisations natives,
diagnostics, tests et nouvelles experiences.

Chlorium n'est pas une mise a jour officielle de Bismuth. Sodium est une
inspiration pour l'objectif d'optimisation ; aucun code de Sodium n'a ete
importe dans ce depot. Aucune affiliation avec Sodium, Geode ou RobTop
n'est revendiquee. Le logo Chlorium a ete genere par IA.

Les executables du jeu, les DLL de Geometry Dash, les donnees des niveaux
telecharges, les sauvegardes et les autres mods ne sont pas fournis ici.
