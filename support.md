# Problème avec Chlorium

Le renderer v0.3 est expérimental. En cas d'écran noir ou de rendu incorrect,
désactiver Chlorium dans Geode et relancer le même passage permet de comparer.
Conserver le nom/ID du niveau, le pourcentage, la version du mod et les autres
mods actifs. Un effet naturellement sombre peut aussi être présent sans Chlorium.

Les anciennes versions alpha.6 sont archivées et ne représentent plus le
renderer actuel. Les résultats et limites sont dans le journal du projet.
Source : https://github.com/stotian/Chlorium (dépôt privé).
