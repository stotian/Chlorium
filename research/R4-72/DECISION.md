Diagnostic renderer profile only, based on R67; never normal installation. A
bounded gateway observes the pinned native rotation call site after the original
Cocos affine helper has executed, before GD writes its resulting position. The
native section callback records the immediate post-arithmetic object fields.
Every original helper/callback still executes once. No gameplay or CPU work is
suppressed. The gateway checks native return address, stack arguments, layer,
owner thread, actor lifetime, PE bodies/import and the private game path.

Two complete render frames, first 128 observed decoration actors, 65,536-row cap.
Each record stores exact native before/after root state, shared affine/center/move
parameters, local rotation and MXCSR. Initial snapshots occur after native stamp
updates. Pending/unclosed operations, ownership changes, overflow or unknown ABI
reject the evidence. Capture is independently audited, always excluded from FPS,
and cannot combine other diagnostics. The call-site patch is disabled afterward;
its single read-only pointer page remains owned for Geode's patch lifetime.

512 independent gateway witnesses match native argument locations, complete
object bytes, FP and LastError. Three malformed-file test groups and seven runner
combination guards pass. Both private profiles compile/link/package.
