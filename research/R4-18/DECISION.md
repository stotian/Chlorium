# R4-18 - Exact elimination of unobserved translation phases

**Keep as an isolated architecture component. No native phase suppression.**

R4-19's complete native producer oracle establishes that moves within one GD
command stamp accumulate; resets occur only on a newer stamp. This replacement
model does not describe those same-command calls. See `../R4-19/DECISION.md`.

R4-12/13 merely postponed the same arithmetic debt. Here an immutable uniform
translation program can eliminate intermediate reset/apply pairs only when a
bit-based dyadic proof establishes that every add/subtract restores exactly
the same canonical double base. Both magnitudes use a common quantum and
strict 53-bit headroom. Otherwise all ordered phases are replayed. No algebraic
reassociation is allowed on unproved inputs. NaN/Inf/subnormals select replay.
A read barrier splits a program and publishes exactly the eager prefix state.
Command storage is bounded to 4096 entries, before allocation.

A real counterexample at ordinary world coordinates invalidates naive last-write
supersession: base nextafter(32768,0), offset .125 then zero loses one double
ULP in the native-style reset/apply sequence. Removing the exactness guard is
caught after two checks. This is why visual similarity alone cannot authorize
skipping phases. Source ownership prevents proof metadata from going stale.

The independent oracle extracts only 119 bytes of the user's owned GD reset
component at runtime, validates PE identity and body fingerprint, supplies a
small ABI adapter and compares positions, offsets, the dirty byte and masked
FP flags. No proprietary game bytes are in Git. This proves the reset primitive,
not the full Area interpreter or the production writer of new offsets.
All checked floating controls and reader prefixes pass; counts in evidence.json.

Nine alternating CPU batches, full final state compared, program construction
and guards included: 32768 objects/64 phases, exact grid 11391.3 -> 283.9 us;
mixed eligibility 11171.6 -> 2302.4 us; full precision 11669.8 -> 4472.7 us.
The last case coalesces zero objects: its gain comes from object-major replay
in a closed observer-free model. Initial copies lie outside both timed paths.
These are model timings, never GD FPS or end-to-end native Area measurements.

## Native integration remains gated

Real Area offsets may be object-dependent, including float quantization even
for a shared parent translation. Uniformity cannot be inferred from a group ID.
Rotations/scales, falloff, alpha/color, sections, collision/target readers,
callbacks, dirty state and command stamps are not covered. A producer must
certify the actual write formula and every intervening reader, or force the
native path. No effect is skipped in the current installed game.

The native reset returns BPL in EAX and its caller branches on AL before a
virtual callback. The actual generated SDK header correctly declares bool;
the auto/decltype source wrapper preserves that type. Any future replacement
must retain this return/callback contract. The arithmetic proof alone cannot
justify eliminating the conditional callback. No reset hook is installed.
